# Resale Finder

メルカリの売却済み記録を、同じ商品・版の公式定価と比較するローカル向けアプリです。対象はゲーム、トレカ、フィギュア、書籍・漫画、限定品です。

## 起動

Docker Desktop を起動し、リポジトリのルートで `docker compose up --build` を実行します。[アプリ](http://localhost:4173) と [APIのヘルスチェック](http://localhost:4173/api/health) を開けます。停止は `docker compose down` です。手動記録は PostgreSQL の名前付きボリュームに保存されます。Compose の設定はローカル利用を前提とします。

画面だけを確認するには、Node.js 22.12 以上で `npm ci`、`npm run dev` の順に実行し、[デモ](http://localhost:5173/?demo) を開きます。このモードの手動記録は同じブラウザーに保存されます。API に接続できない場合もブラウザー保存に切り替わり、手動記録タブに保存先を表示します。デモと PostgreSQL のデータは別管理です。

既存の PostgreSQL ボリュームを使用している場合は、再ビルド前に次を一度実行します。

```sh
docker compose exec db psql -U resale -d resale -c "ALTER TABLE products ADD COLUMN IF NOT EXISTS image_url text NOT NULL DEFAULT '';"
```

## 記録と分析

- 検索は商品名、版・型番、カテゴリが対象です。定価超えは各商品の最新売却価格が公式定価を上回る場合です。
- 商品詳細に公式URL、定価根拠、履歴、価格推移、7日・30日・90日の件数を表示します。
- 売却済みを確認した記録を手動で登録できます。公式商品URLと取引URLは任意です。既存商品を選ぶと同じ商品の履歴に追記します。新規商品には、自分で撮影した写真や掲載許可のある画像の HTTP(S) URL を登録できます。画像が表示できない場合はカテゴリのアイコンを表示します。
- 売却日時と確認日時を個別に記録します。表示は日本時間です。売却日時が空欄の場合は確認日時を価格推移と件数集計に使います。デモの集計基準日は2026年11月8日です。
- 推定利益は売却価格 − 概算販売手数料（10%・円未満切り捨て） − 送料 − 仕入額です。仕入額が空欄の場合は定価を使います。振込手数料やその他の個別費用は含みません。[メルカリの手数料](https://help.jp.mercari.com/guide/articles/65/)

## データの出所

デモの売却履歴は架空です。マリオカート ワールドのパッケージ版は、任天堂の公式商品ページに掲載の希望小売価格（税込）を使用します。他のデモ商品と定価は架空です。手動登録には利用できる記録と定価の根拠を入力してください。個人間取引の売却済みデータに使用できる公式APIや利用許諾を確認できなかったため、メルカリへの自動アクセスは実装していません。メルカリShops API はショップ用の認証が必要です。[メルカリ利用規約](https://static.jp.mercari.com/tos) · [メルカリShops API](https://api.mercari-shops.com/docs/index.html)
